## Liberated Pixel Cup outdoor tiles — Lanea Zimmerman (Sharm)

- Creator: **Lanea Zimmerman (Sharm)**.
- Original creator profile: https://opengameart.org/user/1727
- Original project: http://lpc.opengameart.org/
- Publisher's asset repository: https://github.com/OpenGameArt/LiberatedPixelCup
- Exact source revision: [`f61104a1ecc54e7bce54b82ada7d7ba4c41bc524`](https://github.com/OpenGameArt/LiberatedPixelCup/commit/f61104a1ecc54e7bce54b82ada7d7ba4c41bc524), committed February 21, 2018.
- Source folder: `tileset/original/Sharm/outdoor/PNG/`.
- Selected license: **Creative Commons Attribution-ShareAlike 3.0 Unported**,
  https://creativecommons.org/licenses/by-sa/3.0/.
- Attribution: **LPC outdoor tiles by Lanea Zimmerman (Sharm), CC BY-SA 3.0**.
- Local originals and notices: [`assets/environment_human/lpc/`](../assets/environment_human/lpc/).
- Exact upstream paths, dimensions and SHA-256 hashes:
  [`provenance.json`](../assets/environment_human/lpc/provenance.json).

The upstream README offers the assets under both CC BY-SA 3.0 and GPL 3.0;
this project selects the **artwork's CC BY-SA 3.0 option**. Attribution, the
license link and notice are retained. The included PNGs are unchanged, with
their original transparency, color profiles and pixel dimensions. The artwork
and any adaptations of it remain available under CC BY-SA 3.0. This notice
does not relicense unrelated game code, characters, music or earlier artwork.

Selected sheets supply detailed broadleaf and evergreen foliage, tree trunks
and their existing shadows, grass, dirt paths, rocks, water, natural grassy
shorelines, wooden bridges and waterfall pieces for the currently playable
forest journey. The sheets use a **32×32 source grid**. Complete tree canopy
regions and matching trunks are composed in Godot; original images are not
split, repainted, recolored or regenerated. Terrain transitions and bridge
pieces use the artist's existing atlas regions.

### Provenance evidence and access limits

The OpenGameArt organization's original-asset repository explicitly places the
files under Sharm's name. Its `tileset/original/authors.md` identifies her full
name, creator profile and the second contributor, Daniel Armstrong
(HughSpectrum). Only **Sharm's outdoor PNGs** are selected here; no claim is
made that HughSpectrum drew these particular sheets. The repository's README
links the original Liberated Pixel Cup and style guide and supplies explicit
license choices. The pinned February 2018 archive predates current generative
image workflows and records the established 2012 Liberated Pixel Cup artwork.
These facts are reasonable human-created provenance evidence, not a forensic
guarantee about every historical production step.

The creator's OpenGameArt profile and itch.io pages return network access
denials in this environment. The accessible publisher-owned GitHub repository,
its named-author notice, dated revision and full license were checked directly
on October 23, 2026. No unlicensed mirror, AI image service, generated substitute,
restricted TopDownFantasy-Forest pack or newly sourced audio/font is used.

## Retained existing human artwork

Existing cat characters remain the user's supplied originals. Where retained,
Pixel-Boy's **Ninja Adventure** vegetation/details remain under **CC0**, with
their original files and provenance recorded in
[`assets/overhaul_human/README.md`](../assets/overhaul_human/README.md) and
[`docs/wonderland-polish-credits.md`](wonderland-polish-credits.md).

The save marker uses an unchanged **Kenney Game icon pack** star PNG, **CC0**,
from a dated 2020 distribution. Godot renders it with black fill, a white
outline and a transform bob. Source bytes, license and provenance are recorded
in [`assets/save_star_human/README.md`](../assets/save_star_human/README.md).
No star polygon, texture or new font was generated. Attribution is also
included in the game's existing Credits page.

No original project artwork, soundtrack, license, scene or disabled region is
deleted by the asset integration. This document covers the selected forest
replacement set; it does not invent new provenance for unrelated assets.
Git text normalization is disabled for these new source folders so the original
PNG and license-notice bytes continue to match their provenance hashes on clone.
